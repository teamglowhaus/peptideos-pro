# Font Licensing

All fonts used in this product are licensed under the SIL Open Font License 1.1
(OFL), which permits commercial use, embedding in documents, and distribution of
documents that use the fonts. The fonts themselves are not resold or
redistributed as fonts; they are embedded in the exported PDF files, which the
OFL explicitly allows.

| Font | Designer / Foundry | License | Source |
|---|---|---|---|
| Cormorant Garamond (400, 500, 600, 700, italics) | Christian Thalmann, Catharsis Fonts | SIL OFL 1.1 | Google Fonts |
| Marcellus (400) | Astigmatic (Brian J. Bonislawsky) | SIL OFL 1.1 | Google Fonts |
| Lato (300, 400, 700, italic) | Łukasz Dziedzic | SIL OFL 1.1 | Google Fonts |

Role assignments:

- **Cormorant Garamond** — elegant editorial serif for headings, pull quotes and
  affirmation display text.
- **Lato** — clean, highly legible body font for paragraphs, prompts, labels and
  fine print.
- **Cormorant Garamond Italic** — restrained accent style (used sparingly; no
  script fonts are used anywhere, and no script/italic face is used for body text).
- **Marcellus** — small-caps-flavored display accent for kickers, section labels
  and covers.

The full OFL license text is available at https://openfontlicense.org.
`fetch_fonts.sh` in this folder re-downloads the exact static TTFs used.
